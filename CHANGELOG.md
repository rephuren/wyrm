# История изменений

## Не выпущено

### Добавлено
- сборка цели без санитайзеров `build/plain_json_lite` (только покрытие) и замер трёх режимов на ней: fork-сервер примерно в 10 раз быстрее `fork`+`exec`, `--persistent` ещё в 10 раз быстрее (#6)
- режим `--forkserver`: прогретый процесс цели форкается на каждый вход (протокол: приветствие, pid потомка, статус `waitpid`), таймаут убивает только потомка, краш не перезапускает сервер; на `json_lite` 346/с против 106/с без режимов, при этом `--persistent` быстрее (#3)
- `WYRM_TEST_FILTER` для запуска части тестов

## 0.2.0

### Добавлено
- persistent-режим `--persistent`: один процесс цели вместо `fork`+`exec` на вход (на `json_lite` в 260 раз быстрее при том же покрытии)
- параллельные воркеры `--jobs N` с общей папкой корпуса
- перепроверка крашей из persistent-режима в чистом процессе
- дедупликация крашей по сигнатуре: повторы одного бага схлопываются в одну запись со счётчиком
- учебная цель `stateful`, CI на Ubuntu, сборка с `-Werror`, конфиг `clang-tidy`

### Изменено
- корпус пишется атомарно, нумерация продолжается после перезапуска, повторный запуск с теми же сидами не плодит копии
- понятная ошибка, если цель не запускается
